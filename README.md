> **Instant Peer-to-Peer Wi-Fi LAN File Transfer CLI.** Send or receive large files between laptops, smartphones, and STBs on the same local network at full Wi-Fi Gigabit speed without cloud upload.

---

## 🚀 Quick Install

```bash
pip install speeddrop
```

---

## 🖥️ Usage

### 1. Send File across Local Network
```bash
speeddrop send large_video.mp4
# Output: 🔗 LAN Download URL: http://192.168.1.15:8765/large_video.mp4
```

### 2. Receive Files from Mobile / Other PCs
```bash
speeddrop receive ./downloads
# Output: 📥 SpeedDrop Receiver listening on: http://192.168.1.15:8765/
```
